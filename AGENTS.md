# Coding Agent Instructions

Before every new development session, read `safety.md` completely and follow it.

- Follow the documented project architecture and keep business details centralized.
- Never bypass security controls or expose credentials.
- Review security, performance and scalability impact for every relevant change.
- Run relevant tests after modifications and verify production builds before declaring work complete.
- Update documentation when architecture or deployment behavior changes.
- Never silently remove security functionality.
- Report unresolved security issues and unverified configuration requirements.
- Keep business claims factual; do not invent service areas, certifications, testimonials, projects or addresses.
